Build an order board in this Canvas from my email. If Gmail is not connected yet, tell me how to connect it, then carry on. Ask only for what you cannot work out from the mail. “Which customers or senders send you orders?” and “What do you sell by: cases, pallets, units?”

Make one card per order or quote request, in four columns: New, Quoted, Confirmed and Shipped. Show the customer, the quantity, the amount when the thread states one, and the day it is due. Read each whole thread, my replies included, so a quote I sent counts. Move a card when a later email changes its stage, such as an approval, a purchase order or a shipping notice, and link every card to its thread. Show a running total for each column. Go by what each email says and the names of its attachments.

Under the board, list quotes that have had no answer, oldest first, with the days since I sent them.

Fill the board from recent mail now and attach a Sidekick that updates it as new mail arrives. Use an incoming-mail trigger if the connection supports one. If it only supports scheduled checks, state the actual refresh cadence. If I name teammates whose inboxes should feed the same board, say what each of them needs to do and show whose inbox each card came from. Keep the board within this Canvas's audience.
