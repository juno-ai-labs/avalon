Build a client document checklist in this Canvas from my email. If Gmail is not connected yet, tell me how to connect it, then carry on. Ask only for what you cannot work out from the mail. “Which clients is this for, and what period?” and “Which documents does each client owe you?”

Make a grid with one row per client and one column per document. Tick a box when an email from that client delivers that document, going by what the email says and the names of its attachments. Do not judge whether a document is complete or correct. Show how many of its documents each client has sent, and mark a client ready when every box in its row is ticked. Link each tick to the email that earned it.

Under the grid, list who still owes what, with how many times I have asked and when I last asked. Read my sent mail for that. If I ask for reminders, write them as drafts and leave them in my Gmail Drafts for me to send.

Fill the checklist from recent mail now and attach a Sidekick that updates it as new mail arrives. Use an incoming-mail trigger if the connection supports one. If it only supports scheduled checks, state the actual refresh cadence. If I name teammates whose inboxes should feed the same checklist, say what each of them needs to do and show whose client each row is. Keep the checklist within this Canvas's audience.
