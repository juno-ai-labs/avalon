name: "Shared grocery list"
description: "Add groceries together and see them grouped by store section."
tags:
  - parents
---

Build a shared grocery list in this Canvas that anyone with access can update. Start with an empty list and a prominent add field that works well on a phone. Let people enter plain language such as “2 avocados” and add it in one step. Ask no setup questions.

Automatically group items by store section, such as produce, bakery, dairy, pantry, and frozen. Let people change the section if their store is laid out differently. Provide simple controls to edit a quantity, check off an item, or undo a check-off. Keep checked items out of the active shopping list.

Store the list in shared data so updates show up for everyone with access. Preserve items when more than one person adds or checks off groceries, and keep the list available from this Canvas for the next shopping trip.
