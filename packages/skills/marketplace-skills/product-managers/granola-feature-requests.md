Build a shared feature request board in this Canvas from customer interviews in Granola. If I haven't specified the source, ask “Which Granola folder or interview links should I use?” Read the relevant notes and available transcripts. Pull out explicit feature requests and the customer problem behind each one, with links back to the interviews.

Merge requests that solve the same problem and preserve the evidence from each distinct interview. Give each request a clear title, a short problem statement, and a count of interviews that mentioned it. Keep distinct problems separate even if they point to similar solutions.

Let each teammate cast or retract one vote per request in the shared board. Stack-rank the list by vote count, with interview count breaking ties. Show both counts and preserve votes when later interviews add evidence. Populate the board now and use new Granola interview notes to keep the same request records up to date where supported.
