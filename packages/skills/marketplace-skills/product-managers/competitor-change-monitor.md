Track changes to competitors' pricing, product, and hiring pages in this Canvas. If I haven't already pasted the list, ask “Which page URLs should I monitor?” Take a baseline snapshot for each reachable URL and identify the pricing, product, or hiring details that the page actually shows.

Compare each new snapshot with the previous verified one. Brief me on real changes such as plan prices or limits, features or packaging, and jobs added or removed. For each change, show the previous and current values, when you detected it, and the source link. Ignore presentation changes and other page noise. Track failed or incomplete fetches separately from confirmed changes.

Set up a daily Sidekick check and keep the latest brief and change history in this Canvas. Update the baseline only after a successful fetch and keep unchanged checks quiet. Show when each page was last checked and which pages could not be verified.
