source="exact"Markdown and text send the source string itself. It goes straight into edit_file as oldString.
source="rendered"HTML files and live sites send the rendered element. Rally finds it in the source before editing.
source="converted"PDF, Office and spreadsheet ranges (CSV too) send converted text. Rally rebuilds the file to change it.
truncated="true"A long selection keeps its head and tail. Rally reads the full range before editing.
