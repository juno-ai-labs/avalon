Getting started

Start in
the app.

Most account, workspace, and connection settings live in the Rally desktop app.

Find the right settings

Connected services

Open Settings → Connections to view status, refresh supported authorizations when you are an administrator, disconnect, or configure a connector.

Workspace access

Ask a workspace owner or administrator about invitations, roles, member access, and workspace-wide installations.

Desktop handoffs

If a browser link does not open Rally, launch the desktop app first and try the original action again.

Open Rally Connections ↗

When to contact support

Contact us when the connection status and provider access do not explain the problem, a handoff repeatedly fails, or you cannot reach a workspace you should be able to access. Include the approximate time, Rally region, and any visible request ID.
