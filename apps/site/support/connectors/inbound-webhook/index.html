Inbound
webhook.

Receive signed JSON activity from systems that do not have a native Rally connector.

Create the endpoint

Open Rally → Settings → Connections → Inbound webhook and choose a personal or workspace scope. Rally shows the signing secret once. Save it directly in the sending system’s protected configuration; do not paste it into a work stream or support email.

Workspace webhook creation and secret management require a Rally workspace administrator.

If delivery fails

  1. 1

    Confirm the sender uses the current endpoint and signing secret.

  2. 2

    Confirm the request body is a JSON object and its event type is allowed by the connection.

  3. 3

    Rotate the secret only when the old one may be lost or exposed; rotation invalidates it immediately.

Support details

Send the response status, approximate time, Rally region, event type, and visible request ID. Do not send the signing secret or full event body.
