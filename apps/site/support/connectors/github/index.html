GitHub.

Rally works with repositories, issues, pull requests, Actions, checks, and development events through the Rally GitHub App.

Connect GitHub

Open Rally → Settings → Connections → GitHub. A personal connection acts with your authorized GitHub identity. A workspace connection installs the Rally GitHub App and lets administrators select the repositories Rally can reach.

Repository selection is an access boundary. If a repository is missing, check the GitHub App installation and Rally’s repository access settings rather than reinstalling blindly.

If a repository is unavailable

  1. 1

    Confirm the Rally GitHub App is still installed on the expected GitHub account or organization.

  2. 2

    Confirm the repository is included in that installation and in Rally’s selected repository policy.

  3. 3

    Check the GitHub connection’s Status column in Rally. If it says Reconnect required, ask a workspace owner or administrator to use Refresh.

Support details

Send the GitHub organization and repository names, not a token or private key. Include a visible request ID when available.
