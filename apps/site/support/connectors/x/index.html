Public X.

Read public X timelines, threads, replies, and Lists through Rally’s workspace connector.

What this connector does

Public X is read-only and workspace-scoped. It uses a Rally-managed third-party retrieval service rather than your personal X credentials. It cannot post, like, follow, send direct messages, or access private X content.

A Rally workspace owner or administrator controls whether the connection is available.

If a public post is missing

  1. 1

    Confirm the account, post, thread, reply, or List is public and still available on X.

  2. 2

    Check the Public X connection’s Status column in Rally.

  3. 3

    Retry with the canonical public X URL or exact public identifier.

Support details

Send the public URL, approximate time, Rally region, and visible request ID. Do not send X credentials or private content.
