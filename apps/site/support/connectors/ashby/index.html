Ashby.

Connect your account for recruiting tools, and connect workspace events independently. Either can be connected first.

Connect for me

In Rally Settings → Connections → Ashby, choose Connect for me and complete Ashby's browser sign-in. Ashby's beta MCP service requires your organization's opt-in and an eligible Ashby account. The available tools and records depend on that account's access.

Personal sign-in never creates webhooks. Recruiting queries and updates use your personal connection. Rally does not ask you to confirm individual tool calls.

Connect for workspace

A Rally workspace administrator chooses Connect for workspace and supplies an administrator-provided Ashby API key with Read API Keys (apiKeysRead) and Write API Keys (apiKeysWrite) permissions. Enter it only in the password field in Settings.

Rally automatically subscribes to Ashby’s documented recruiting events through one shared workspace installation. There are no event checkboxes during setup; choose which events an automation uses when configuring the automation. Additional personal connections do not register additional workspace webhooks. The workspace connection provides no recruiting query or update tools.

Organization events can concern recruiting records whose visibility differs from a personal query. Connecting authorizes organization event subscriptions. If Ashby rejects a subscription, its status remains visible under Manage events while other subscriptions continue. Rally encrypts credentials and stores admitted events in the workspace's selected region; Ashby remains an external service.

Check and recover

Personal authorization and workspace delivery have separate status. Refresh your personal connection to sign in again. For workspace events, open Manage events to inspect registrations, verification, and last delivery. Refresh status reads the saved state. Test attempts supported repair and then checks connection health.

If a create result is unknown, inspect the exact destination in Ashby before supplying the existing webhook ID. Do not recreate the connection repeatedly. Signing-key rotation that cannot be verified requires manual action.

Removing a workspace connection immediately stops Rally access. Provider cleanup may remain pending. Forgetting the local cleanup credential leaves any remaining webhook removal to your Ashby administrator.

For support, share the connection ID, region, error, and affected time. Never share API keys, signing secrets, OAuth tokens, or candidate content.
