Granola.

Connect personally through Granola’s browser sign-in, or connect workspace notes and transcripts with an administrator-created Workspace API key.

Generate a Granola Workspace API key

You must be a Granola workspace administrator on a Business or Enterprise plan.

  1. 1

    Open the Granola desktop app.

  2. 2

    Go to Settings → Connectors → Workspace API keys.

  3. 3

    Select Create new key.

  4. 4

    Copy the key, then open Rally → Settings → Connections → Granola → Connect workspace and paste it into the password field.

What the key can access

Workspace keys can read public workspace notes and notes in spaces where Granola API access is enabled. They cannot read other private notes. Rally encrypts the key in your selected data region and never returns it to the desktop.

Personal connection and recovery

Choose Connect for me for personal meeting context. Personal connections use Granola’s browser sign-in and do not require an API key. Check the connection’s Status column in Rally. A workspace owner or administrator can use Refresh for a personal Granola authorization; workspace Granola connections do not expose that action, so contact support if workspace delivery stops.
