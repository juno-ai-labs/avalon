Generate a Granola Workspace API key

A workspace-wide Granola connection requires a Workspace API key. You must be a Granola workspace administrator on a Business or Enterprise plan.

  1. 1

    Open the Granola desktop app.

  2. 2

    Go to Settings → Connectors → Workspace API keys.

  3. 3

    Select Create new key.

  4. 4

    Copy the key, then open Rally → Settings → Connections → Granola → Connect workspace and paste it into the password field.

What the key can access

Workspace keys can read public workspace notes and notes in spaces where Granola API access is enabled. They cannot read other private notes. Rally encrypts the key in your selected data region and never returns it to the desktop.

Connecting Granola only for yourself? Choose Connect for me in Rally instead. Personal connections use Granola’s browser sign-in and do not require an API key.

Slack troubleshooting

Open Rally → Settings → Connections to test, reconnect, or disconnect a Slack installation. Open Rally’s Home tab in Slack to link your Slack identity, start a task, and manage notifications.

Include the approximate time, your Rally region, and any visible request ID. Never send Slack tokens, OAuth codes, link tokens, passwords, or private message contents by email.
