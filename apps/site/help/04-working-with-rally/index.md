So far this book has been about the room: the message box, the files you drop
in, the people you invite. This chapter is about the one in the room who never
goes home. That is Rally, the agent.

Yes, the agent has the same name as the app. You were warned about this in
chapter 1, and this is the last time it will come up. When this chapter says
"Rally", it means the agent: the thing that reads your request, decides what to
do, and does it.

## One agent per conversation

Every Channel has its own Rally. So does every Breakout, and so does every
conversation you have with a Sidekick. Each one is a single, ongoing thread of
work. It remembers what was said earlier in that conversation, it knows which
files are in it, and it picks up where it left off when you come back
tomorrow. It is less like a search box and more like a colleague who has been
sitting in on the meeting.

That colleague has a particular way of working, and knowing it makes
everything else in this chapter click:

- **It acts first.** Ask for something and Rally starts on it. It does not
  reply with "Shall I go ahead?" and wait for you.
- **It shows its plan for long jobs.** For anything with several steps, Rally
  says what it is about to do, then reports back every few steps so you can
  steer.
- **It looks things up rather than guessing.** Dates, links, email addresses
  and numbers come from a tool, from you or from a file. If none of those has
  the answer, Rally asks.
- **It never asks you to approve each step.** There is no queue of "Allow this
  tool?" pop-ups. You say what you want, and Rally does the work.

## It can be wrong

Rally is good, and it is honest about where it got things, but it is not
infallible. A web page can be out of date. A memory can be stale. A
spreadsheet can have a typo in it that Rally faithfully carries into its
summary. When something matters (a number going to a client, an email going to
your boss, a change to real code), read what Rally did before you rely on it.
The activity rows and sources from
[chapter 2](../02-working-in-a-channel/index.md) are there for exactly that.

## What is in this chapter

The pages that follow start with how Rally decides what to do and why it
rarely stops to ask. Then come the things it can actually do for you. It can
search the web and read pages, and open links in a browser right beside the
conversation. It has its own private computer for running code, crunching data
and working on GitHub repositories. It can draw pictures and record voices. It
can remember things between conversations and set itself a reminder to come
back later. And for big jobs it can call in helpers, while keeping receipts so
nothing gets done twice.

None of this needs switching on. You ask in plain words, and Rally reaches for
the right tool. The point of these pages is to show you what is in the toolbox,
so you know what to ask for.
