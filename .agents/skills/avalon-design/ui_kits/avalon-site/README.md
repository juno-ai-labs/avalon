# Avalon marketing site UI kit

A recreation of `apps/site` (with-avalon.com) from juno-ai-labs/avalon.

| Section | Source |
| --- | --- |
| Header, hero, art-direction picker | `apps/site/index.html`, `.hero-*` and `.theme-picker` in `src/styles.css` |
| Signal strip | `.signal-strip` |
| How it works | `.how-section`, `.steps-grid` |
| Product tour window | `.workspace-demo` |
| Features grid | `.feature-grid`, `.feature-card` |
| Connections | `.integrations-section` |
| Download panel + footer | `.download-panel`, `.site-footer` |

**Interaction:** the hero art-direction picker (Warp / Mesh / Trace / Orbit) swaps the biome photograph, exactly as the live site does.

**Not recreated:** the comparison table, FAQ, and the legal/trust-center template. Hero copy and headline pairs are lifted verbatim from the live page.
