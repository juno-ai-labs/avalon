# Avalon icon variants

These optional 1024×1024 icon treatments preserve the woven Avalon mark while giving users five distinct visual choices:

- `avalon-icon-aurora.png`
- `avalon-icon-sunset-sherbet.png`
- `avalon-icon-pool-party.png`
- `avalon-icon-confetti.png`
- `avalon-icon-cosmic.png`
- `avalon-icon-ludicrous-speed.png`
- `avalon-icon-hologram.png`
- `avalon-icon-ruby.png`
- `avalon-icon-neon-stitch.png`
- `avalon-icon-blueprint.png`

They are customization assets, not replacements for the canonical mark in `assets/brand/avalon-mark-source.png`. The production app icon remains unchanged until a native user-selectable icon flow is implemented and reviewed according to `docs/DESKTOP_ICONS.md`.
